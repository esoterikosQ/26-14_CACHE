# PHDQ BLT cache

An experimental, opt-in cache for the converted BLT model used by `phdq3`.
This repository is independent of the training repository: it contains the
cache implementation, its tests, design history, experiment plan, and small
JSON evidence. It does not contain model weights, datasets, tokenizer files,
neural-model training code, or Slurm jobs.

The current guarded path recomputes entropy patching and the local encoder on
every generated byte. It reuses the global transformer's result when patch
starts remain unchanged, and refreshes with a full forward when the two best
legal byte logits are within the configured guard margin. Decoder KV reuse is
off in the validated guarded path. The public `GlobalPrefixReuse` class
expects the `phdq3` OSC BLT module layout; it is not a generic Transformers
cache.

```bash
python -m pip install --no-deps "phdq-blt-cache @ git+https://github.com/esoterikosQ/blt-cache.git@<COMMIT_SHA>"
```

The GitHub URL is an **example for the future repository**, not a published
dependency yet. Pin an actual commit after the new repository has been created
and tested. The host environment needs BF16-capable PyTorch and the matching
converted BLT model. In Python:

```python
import torch
from phdq_blt_cache import GlobalPrefixReuse

model.eval()
with torch.inference_mode():
    cache = GlobalPrefixReuse(model, reuse_decoder=False)
    output, _, _, _ = cache.run(input_ids, logits_to_keep=1, guard_margin=1.0)
```

This low-level call does not replace token selection, stopping, or text
decoding. The `phdq3` generation adapter remains responsible for those steps.
Read [docs/HANDOFF.md](docs/HANDOFF.md) before changing this API or moving the
training repository to the external package.

## Opt-in Count Patcher Research

The separate [patcher plan](BLT-PATCHER.md) and [execution status](task.md)
cover an experimental count-based replacement for the neural entropy patcher.
Install its numerical dependencies with `python -m pip install -e '.[patcher]'`
and explicitly import `phdq_blt_cache.count_patcher`. The existing cache API
and defaults are unchanged; no BLT patcher replacement is enabled automatically.

The module provides causal counts, finite-window expiry, all-shorter-context
mixtures, serializable incremental state, and constrained fixed-feature fitting.
Research scripts keep datasets, tables, labels, and fitted artifacts outside
this source tree. The initial two K=8 configurations reached validation F1 of
about 0.626, below the preregistered 0.90 gate; neither is approved for integration.
Korean follow-up training and comparison are assigned to Neuron H200, with
access, transfer, and job submission performed by the user.
